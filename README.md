Чат-клієнт з підтримкою зображень 📱
Сучасний чат-клієнт з графічним інтерфейсом на Python з можливістю обміну текстовими повідомленнями та зображеннями.

📋 Опис програми
Це клієнтська програма для чату, яка дозволяє:

Підключатися до чат-сервера

Надсилати текстові повідомлення

Надсилати зображення (JPG, JPEG, PNG)

Отримувати повідомлення від інших користувачів у реальному часі

Автоматично підлаштовувати інтерфейс під розмір вікна

🛠️ Встановлення
1. Клонуйте репозиторій
bash
git clone <url-репозиторію>
cd <назва-папки>
2. Встановіть залежності
bash
pip install customtkinter Pillow
🚀 Запуск
1. Спочатку запустіть сервер
bash
python server.py
2. Потім запустіть клієнт
bash
python menu.py
📖 Як користуватися
Вхід у чат
Введіть ваше ім'я користувача

Введіть IP-адресу сервера (зазвичай 127.0.0.1 для локального сервера)

Введіть порт (за замовчуванням 8080)

Надсилання повідомлень
Напишіть текст у поле введення внизу

Натисніть кнопку > або Enter

Надсилання зображень
Натисніть кнопку 📁

Виберіть файл (jpg, jpeg, png)

За бажанням додайте текстовий підпис

Натисніть кнопку > для відправки

💡 Порада: Щоб скасувати вибір зображення - клацніть по ньому лівою кнопкою миші# logitalk
